# Cord Staffing Solutions — Vercel Website

Plain HTML/CSS/JavaScript corporate recruitment website. No Node.js, build step, or framework is required.

## Deploy to GitHub + Vercel
1. Create a GitHub repository, e.g. `cord-staffing-website`.
2. Upload the contents of this folder to the repository root. `index.html` must be in the root.
3. In Vercel choose **Add New → Project** and import the GitHub repository.
4. Framework preset: **Other**.
5. Build command: leave empty.
6. Output directory: leave empty.
7. Click **Deploy**.
8. Vercel will give you a `*.vercel.app` URL.

## Contact form
The form is front-end ready but does not send email yet. Connect it to your chosen form/email backend before production.

## Editing
Main content: `index.html` | Design: `style.css` | Interactions: `script.js`.

The supplied Cord Staffing content was used as the source. Missing US address/email details were not invented.
